# Student Information System

My first full-stack web application — a basic Student Information System built using HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

## Live Demo

[Open Student Information System](https://student-information-system-bxjc.onrender.com/)

## Features

- Insert student information
- Display student information
- Update student information
- Delete student information

## Technologies & Tools Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- TiDB Cloud
- GitHub
- Render
- Visual Studio Code

## How It Works

The frontend sends requests to the backend using APIs.  
The backend processes the requests and communicates with the database using SQL queries.

**Frontend → API → Backend → Database**
